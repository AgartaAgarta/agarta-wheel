# Agarta Wheel

Стартовый лендинг для сервиса **Agarta Wheel** — интерактивного колеса фортуны для лидогенерации.

## Что внутри

- первый экран с оффером и CTA-кнопками;
- демонстрационный блок с колесом фортуны и простой анимацией вращения;
- блок преимуществ сервиса;
- форма заявки на демо;
- адаптивная верстка для десктопа, планшета и мобильных устройств;
- чистая статическая структура без сборки и зависимостей.

## Структура

```text
.
├── index.html   # Разметка лендинга
├── styles.css   # Стили и адаптив
├── script.js    # Интерактив колеса
└── README.md    # Инструкция запуска
```

## Запуск локально

Проект не требует установки пакетов. Достаточно открыть `index.html` в браузере.

Для запуска через локальный сервер можно использовать Python:

```bash
python3 -m http.server 4173
```

После запуска откройте страницу:

```text
http://localhost:4173
```

## Деплой

Лендинг можно разместить на любом статическом хостинге: GitHub Pages, Netlify, Vercel, Cloudflare Pages или обычном веб-сервере.
