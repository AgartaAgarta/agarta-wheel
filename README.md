# Agarta Wheel

Стартовый лендинг для сервиса **Agarta Wheel** — интерактивного колеса призов для роста заявок, сбора контактов и подключения маркетинговых интеграций.

## Что внутри

- первый экран в стиле промо-сервиса с оффером, CTA, демо-колесом и формой заявки;
- переключатель дневной и ночной темы в верхней панели, по умолчанию включена светлая тема;
- УТП-блок с преимуществами: быстрый запуск, отсутствие кода, интеграции, тестовый режим, аналитика, API и вебхуки;
- блок интеграций с Telegram-ботом, CRM, Google Таблицами, email-сервисами, Webhook и API;
- чисто отрисованные SVG/CSS-иконки без внешних графических ассетов;
- адаптивная верстка для десктопа, планшета и мобильных устройств;
- статическая структура без сборки и зависимостей.

## Сохранённые блоки лендинга

1. **Первый экран** — оффер, навигация, переключатель темы, колесо призов и форма заявки.
2. **УТП-блок** — карточки преимуществ сервиса и ключевые сценарии использования.
3. **Интеграции** — перечень сервисов для подключения Telegram, CRM, таблиц, email, Webhook и API.

## Структура

```text
.
├── index.html   # Разметка лендинга
├── styles.css   # Светлая/тёмная темы, визуал и адаптив
├── script.js    # Переключатель темы и интерактив колеса
└── README.md    # Инструкция запуска
```

## Запуск локально

Проект не требует установки пакетов. Достаточно открыть `index.html` в браузере.

Для запуска через локальный сервер можно использовать Python:

```bash
python3 -m http.server 4173
```

После запуска откройте страницу:

```text
http://localhost:4173
```

## Деплой

Лендинг можно разместить на любом статическом хостинге: GitHub Pages, Netlify, Vercel, Cloudflare Pages или обычном веб-сервере.
